# NyaNet - Una comunidad amigable

![Logo de NyaNet](./nyanet.png)

# Introducción

NyaNet es una red social de código abierto que busca la interacción con personas reales al usar un sistema de solo por invitación para evitar bots, y permite a sus usuarios expresarse y comunicarse de forma mucho más cercana con una experiencia totalmente distinta a la regular.
